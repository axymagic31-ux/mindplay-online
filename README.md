# MindPlay Online — prototype

Prototype awal untuk belajar memasang server MindPlay Online.

## Menjalankan secara lokal
1. Install Python 3.10 atau lebih baru.
2. Jalankan `pip install -r requirements.txt`
3. Jalankan `uvicorn server:app --host 0.0.0.0 --port 8000`

Catatan:
- Ini prototipe belajar, belum siap untuk turnamen atau penggunaan publik serius.
- Ruangan dan hasil disimpan di memori; data hilang jika server restart.
- Jangan memasukkan kata sandi atau data pribadi.
